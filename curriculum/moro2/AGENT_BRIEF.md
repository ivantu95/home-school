## Форма главы
- `const CHAPTER = { number: N, title: '…', minutes: M, language: 'ru', next: '../chNN+1/' };` (для гл. 59 без `next`).
- Шаги: `intro` (как в образце: «Раздел U · Глава N», название, подзаголовок) → 4–7 учебных шагов → 2–4 «Проверь себя» между ними (`q1`, `q2`…) → `wrap` (3–4 вывода) → 2 итоговых набора `final1`, `final2` на `SCREEN` с меткой `'Итоговое задание   1 из 2'` → `finish` (`finishCard`).
- Озвучка ~3–4 минуты (make_timings печатает итог). intro: «Глава <порядковое>. <Название>. [[sub]]…»; finish: «Молодец! <Порядковое с заглавной> глава пройдена.» (порядковое числительное дано в задании).
- **Главы «Повторение»**: короткие анимированные напоминания главных идей раздела (2–4 шага) и больше практики: 4–6 проверок/итоговых наборов, задачи из «Что узнали. Чему научились», «Проверим себя», «Странички для любознательных».

## Содержание и подача
- Для 7–8 лет: тепло, просто, на «ты», без сюсюканья. Короткие предложения. Числа в озвучке — словами («тридцать пять»), на экране — цифрами.
- Картинка объясняет через изменение: пучки палочек-десятков, линейки, блоки, числовой луч, циферблат, кружки по группам — всё рисуется кодом SVG. Иллюстрации учебника не копируй. Тексты задач пересказывай своими словами, числа можно менять.
- Одна новая вещь за раз; один цвет — один смысл (см. BOOK.md); масштаб честный, иначе подпись «нарисовано крупно/мельче».
- Покажи типичную ошибку (зачеркнуть красным `COL.bad`), затем верный путь.
- Обозначения российской школы: минус «−» (U+2212), умножение «·», деление «:», единицы кириллицей (см, дм, м, р., к., ч, мин). В `M()` латиница становится курсивом (это хорошо для буквенных выражений a, b, c, x).
- Вопросы: `blanks` (вписать число), `grid` (знаки `<`,`=`,`>` с горячими клавишами `'<'`,`'='`,`'>'`, `{multi:false, text:true}`), `choice` (у каждого неверного варианта — своё объяснение ошибки), `pickEls` (щёлкнуть нарисованный объект). У `blanks` — `why` и `hint`. id: `c-…` для проверок, `p-…` для итоговых. Карточка не закрывает то, о чём спрашивают (`BAND` снизу, `{x,y,w,cls:'side'}` сбоку/сверху, `SCREEN` для итоговых).
- ВСЕ ответы и вычисления проверь (можно `python3 -c`). Ответ `blanks` — точное число строкой.
- Грамматика русского языка без ошибок; «ё» где положено.
