# Мерим и считаем — план книги

Компактное текущее состояние для работы над главами. Статус глав — в `chapters.md`, раскадровки и заметки — в `chapters/chNN.md`.

## Intake
- Читатель: второклассница, занимается дома с родителем · Тон: тёплый, простой, на «ты», без сюсюканья · Язык: русский · Гид: знак бесконечности из шаблона Papermorph.
- Slug: `moro2` · Код языка: `ru` · Картинки: только код/SVG, иллюстрации из учебника не копируются.
- Источник: `source/1490300180_…_moro-m.i.-i-dr_2012-96s-1.pdf` (М. И. Моро и др., «Математика. 2 класс», ч. 1, 2012) и рабочая тетрадь ч. 1 (`source/1248_…`). Сканы без текстового слоя.
- Номер страницы учебника = страница PDF − 2. Оглавление — с. 98 PDF.

## Структура проекта (соответствие папкам Papermorph)
- `curriculum/moro2/` ↔ `books/<book>/` — план, карта глав, раскадровки (не публикуются).
- `lessons/moro2/chNN/narration.ru.json` ↔ `content/<book>/chNN/` — тексты озвучки.
- `website/moro2/` ↔ `site/<book>/` — готовая статическая книга.
- `tools/moro2/` — скрипты: оценочные тайминги, снимки кадров, e2e-прогон.

## Conventions (утверждаются после пилота)
- Вид: тёмная «доска» движка. Цвета: сантиметр/«целое» — `COL.whole` (голубой), миллиметр/выделение — `COL.task` (оранжевый), сравнение-ловушка — `COL.bad`, верный знак — `COL.good`. Метр — жёлто-оранжевые блоки «складного метра».
- Масштаб: линейка 120–150 px на 1 см; если рисунок не в масштабе — подпись «нарисовано крупно/мельче».
- Озвучка: голос `ru-RU-SvetlanaNeural`, rate `-8%`. Числа пишем словами, где их читают вслух; на экране — символы.
- Без MP3 (до запуска `tts.py`) урок читает голос браузера по субтитрам (лучше всего в Microsoft Edge — там нейронные голоса Svetlana/Dariya). Тайминги — `tools/moro2/make_timings.py`.
- Вопросы: «Проверь себя» после каждой новой идеи; знаки сравнения — `grid` с клавишами `<`, `=`, `>`; переводы единиц — `blanks`; задачи — `choice` с разбором типичной ошибки.
- Предметные правила: сравниваем только после перевода в одинаковые единицы; показываем ловушку «20 > 2» и зачёркиваем её.

## Helpers (`website/moro2/lib/units.js`)
- `uRuler(p, x0, y, u, n, {mm})` — линейка; `uBracket(...)` — скобка с крупной подписью; `uVBrace(...)` — вертикальная скобка; `uBlocks(...)` — ряд блоков (дециметры метра); `uLadybug(...)`.

## Изменения движка в этой книге (`website/moro2/lib/engine.js`)
- Интерфейс переведён на русский.
- Запасной голос браузера (`SP`, `spTick`, `spBusy`): при отсутствии MP3 читает субтитры по предложениям; шаг ждёт конца фразы (не дольше 8 с); пауза останавливает речь; ошибки синтеза не останавливают урок.
